# SchoolPay

تطبيق Flutter مخصص لمدرسة واحدة لإدارة الرسوم والأقساط والدفعات وسندات القبض، مع بوابة مبسطة لولي الأمر.

## نطاق MVP

- دخول المدرسة / ولي الأمر
- إدارة الطلاب وأولياء الأمور
- تحديد إجمالي الرسوم لكل طالب
- إنشاء خطة أقساط شهرية أو مخصصة
- تسجيل دفعة يدوية
- إصدار سند قبض برقم مرجعي
- عرض المدفوع والمتبقي وحالة الأقساط
- واجهة ولي الأمر لعرض أبنائه وسجل الدفعات
- تجهيز معماري لإضافة Supabase ثم الكريمي/جيب لاحقًا

## التقنية

- Flutter 3.x
- Dart
- Material 3
- طبقة Repository قابلة للاستبدال لاحقًا بـ Supabase/API

## تشغيل المشروع

```bash
flutter pub get
flutter run
```

## الحسابات التجريبية

في النسخة الحالية لا يوجد Backend بعد. اختر نوع الدخول من شاشة البداية:
- إدارة المدرسة
- ولي الأمر

## الخطة

### المرحلة 1 — MVP الحالي
1. هيكل التطبيق والهوية
2. لوحة المدرسة
3. الطلاب والرسوم
4. الأقساط
5. تسجيل الدفعات
6. سندات القبض
7. لوحة ولي الأمر

### المرحلة 2 — Backend
- Supabase Auth
- PostgreSQL
- صلاحيات المدرسة وولي الأمر
- تخزين حقيقي للطلاب والدفعات والسندات

### المرحلة 3 — التشغيل الحقيقي
- PDF/طباعة السند
- إشعارات واتساب/SMS
- تقارير التحصيل والمتأخرات
- نسخ احتياطي وسجل تدقيق

### المرحلة 4 — الدفع الإلكتروني
- Payment Gateway abstraction
- الكريمي
- جيب
- محافظ يمنية أخرى
- Webhooks والتحقق من حالة الدفع

## ملاحظة محاسبية مهمة

لا يتم حذف سند قبض بعد إصداره. عند وجود خطأ يتم إلغاؤه مع الاحتفاظ بالسجل لأغراض التتبع والمراجعة.
